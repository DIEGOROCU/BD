# Repositorio de Bases de Datos - UCM

## Descripción

Este repositorio contiene material educativo de **Bases de Datos** de la Facultad de Informática de la Universidad Complutense de Madrid (UCM). Incluye acertijos SQL desafiantes, prácticas estructuradas y resúmenes teóricos sobre SQL y PL/SQL.

## 📁 ACERTIJOS

Colección de acertijos SQL de complejidad creciente que exploran conceptos avanzados de consultas:

- **Acertijo1.sql** - Operaciones básicas con tablas relacionadas (patrones, barcos, reservas)
- **Acertijo2.sql** - Consultas con JOIN y filtrado de datos
- **Acertijo3.sql** - Subconsultas y agregaciones
- **Acertijo4.sql** - Operaciones con múltiples tablas y condiciones complejas
- **Acertijo5.sql** - Consultas avanzadas con GROUP BY y HAVING
- **Acertijo6.sql** - Análisis de datos con agregaciones y ordenamientos
- **Acertijo7.sql** - Operaciones complejas y derivadas
- **Acertijo8_MultiC.sql** - **Multiconjuntos**: Trabajar con conjuntos duplicados y operaciones de cardinalidad
- **Acertijo9_Prim.sql** - **Números Primos**: Algoritmos SQL para identificar y analizar números primos
- **Acertijo10_PaNo.sql** - **Paridad sin COUNT**: Determinar si hay cantidad par o impar de elementos sin usar la función COUNT

**extensiones.sql** - Extensiones SQL avanzadas (vistas, índices, triggers, procedimientos almacenados)

## 📁 PRACTICAS

Prácticas estructuradas que aplican conceptos de bases de datos en escenarios realistas:

- **Practica1.sql** - Diseño de esquemas con múltiples tablas (programadores, analistas, proyectos)
- **Practica2.sql** - Operaciones CRUD y consultas de datos complejas
- **Practica3.sql** - Agregaciones, análisis de datos y reportes

**extensiones.sql** - Extensiones SQL avanzadas para las prácticas (vistas, índices, funciones personalizadas)

## 📁 RESUMEN

Documentación teórica de referencia en LaTeX:

- **PL_SQL_BASICO/** - Conceptos fundamentales de PL/SQL (sintaxis, variables, control de flujo)
- **PL_SQL_AVANZADO/** - Temas avanzados (procedimientos, funciones, triggers, paquetes)
- **PL_SQL_EXAMEN/** - Material de preparación para evaluaciones
- **SQL/** - Referencia completa de SQL estándar y extensiones Oracle

## Tecnología

- **Lenguaje**: SQL y PL/SQL
- **Sistema de Gestión**: Oracle SQL
- **Documentación**: LaTeX

## Cómo usar este repositorio

1. **Acertijos**: Resuelve los acertijos en orden para practicar SQL progresivamente. Los últimos requieren pensamiento algorítmico avanzado.
2. **Prácticas**: Implementa ejercicios aplicados en contextos realistas.
3. **Resúmenes**: Consulta la teoría en la carpeta RESUMEN cuando necesites conceptos teóricos.
4. **Extensiones**: Estudia extensiones.sql para ver implementaciones avanzadas de vistas, índices y funciones.
