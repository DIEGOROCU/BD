# Tema 4: PL/SQL Avanzado

Resumen de 2 páginas sobre características avanzadas de PL/SQL.

## Contenido

1. **Procedimientos Almacenados**: CREATE PROCEDURE, parámetros IN/OUT/IN OUT
2. **Funciones**: CREATE FUNCTION, uso en consultas
3. **Triggers**: BEFORE/AFTER, FOR EACH ROW, :NEW/:OLD, INSTEAD OF
4. **Paquetes**: CREATE PACKAGE, especificación y cuerpo
5. **Manejo de Excepciones**: Excepciones predefinidas y personalizadas
6. **Cursores Avanzados**: Parámetros, FOR UPDATE, REF CURSOR
7. **Control Avanzado**: CASE, loops con etiquetas, CONTINUE
8. **Colecciones**: VARRAY, Nested Table, Associative Array
9. **SQL Dinámico**: EXECUTE IMMEDIATE
10. **Transacciones**: AUTONOMOUS_TRANSACTION, SAVEPOINT
11. **Ejemplos Prácticos**: Integración de conceptos
